# Flight Universe — Runtime Data & Asset Attribution

Flight Universe intentionally keeps source attribution visible in the in-game HUD and documents the major upstream providers here.

- **Three.js** — MIT License.
- **NASA Science 3D Resources** — NASA Global Hawk and Space Shuttle 3D models. NASA states its 3D resources are free to download and use; NASA Images and Media Usage Guidelines still apply.
- **OpenSkyFlight / Rafale model** — Rafale GLTF source used by this prototype. See that project's source/model attribution for the original asset provenance.
- **Esri World Imagery** — Earth imagery streamed at runtime. Provider terms and required attribution apply.
- **AWS Terrain Tiles / Mapzen Terrarium** — Earth elevation tiles decoded client-side.
- **OpenStreetMap contributors** — building footprints/tags and place search via Nominatim/Overpass. OSM data licensing and public-service usage policies apply.
- **JPL Solar System Dynamics** — approximate planetary-position formulae and orbital elements used for Mercury through Neptune.
- **Solar System Scope textures** — planet texture set used at runtime where available; relevant texture releases are CC BY 4.0 and combine NASA-derived data with artistic processing/gap filling.
- **Three.js example textures** — Moon texture.

No third-party font files are bundled.
